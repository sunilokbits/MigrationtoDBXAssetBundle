            Data Quality Checks Implemented
            STANDARD
          


          
          

            

              
              

                
🥉 Bronze Layer DQ

                

                  
✓ DQ-01 Empty file detection — skip on 0 rows

                  
✓ DQ-02 Null-key row detection — all data cols null

                  
✓ DQ-03 Duplicate detection — row-level dedup count

                  
✓ DQ-04 Schema drift detection — new/missing columns

                  
✓ DQ-05 Quarantine flagging — bad rows flagged, not dropped

                  
● Audit __bronze_ts, __source_table, __is_quarantined

                  
● Metrics DQ score saved to __dq_metrics Delta table

                

              

              
              

                
🥈 Silver Layer DQ

                

                  
✓ DQ-01 Quarantine filter — exclude flagged Bronze rows

                  
✓ DQ-02 All-null row removal — drop empty records

                  
✓ DQ-03 Per-column null % — flag cols >80% null

                  
✓ DQ-04 Deduplication — remove exact duplicates

                  
✓ DQ-05 String trimming — whitespace normalization

                  
✓ DQ-06 Empty→NULL — empty strings to NULL

                  
✓ DQ-07 Row count anomaly — >50% change alert

                  
● Audit __dq_status (passed/warn), __silver_ts

                  
● Metrics DQ score + breakdown → __dq_metrics

                

              

            

            
            

              ✓ Restore Points — auto version snapshot before each write
              ✓ Auto Rollback — reverts table on write failure
              ✓ Run History — DQ metrics tracked per run in wf_run_history
              ✓ DQ Metrics Table — __dq_metrics with score, nulls, dupes, drift
            

          


          
          

            

              
              

                
⚡ DLT Bronze Expectations

                

                  
✕ dq01 expect_or_drop — __landing_ts IS NOT NULL

                  
✓ dq02 expect — __source_system IS NOT NULL

                  
✓ dq03 expect — __batch_id IS NOT NULL

                  
✓ dq04 expect — data freshness (<7 days)

                  
✓ dq05 expect — not all audit columns null

                  
● Auto Loader — streaming ingestion + schema evolution

                  
● Metrics — auto-tracked in DLT event log

                

              

              
              

                
⚡ DLT Silver Expectations

                

                  
✕ dq01 expect_or_drop — __bronze_ts IS NOT NULL

                  
✕ dq02 expect_or_drop — __is_quarantined = false

                  
✓ dq03 expect — __source_table IS NOT NULL

                  
✓ dq04 expect — bronze freshness (<7 days)

                  
✓ dq05 expect — source table name not empty

                  
● Dedup — dropDuplicates() on all columns

                  
● Trim — whitespace normalization on strings

                  
● Metrics — auto-tracked in DLT event log

                

              

            

            

              ✕ = expect_or_drop — invalid rows auto-dropped
              ✓ = expect — tracked but rows kept (visible in DLT UI)
              ● = Built-in DLT capability (no custom code needed)
