Databricks Community Edition (Free)

Community Edition is free and great for learning. It uses a different URL pattern and has some limitations:

  • URL: https://community.cloud.databricks.com
  • Single-node clusters only (no autoscaling)
  • Jobs API has limited functionality
  • No serverless compute — converted jobs will use classic clusters
  • Notebooks and basic job scheduling work fine

Bricksfactory fully supports Community Edition for analysis, conversion, and deployment!

Get Started with Community Edition
Free signup + token generation steps

Don't have an account? Sign up free at community.cloud.databricks.com

Step 1: Sign Up / Log In
  1. Go to community.cloud.databricks.com
  2. Click "Sign Up" (or log in if you have an account)
  3. Verify your email and complete registration
Step 2: Generate Access Token
  1. Once logged in, click your user icon (top-right)
  2. Select "Settings"
  3. Go to "Developer" tab → "Access Tokens"
  4. Click "Generate New Token"
  5. Name it Bricksfactory, set lifetime (e.g., 90 days)
  6. Click "Generate" and copy the dapi... token
  7. Paste the token in the field on the left

Security: Token is only stored in-memory for this session. Never saved to disk.

How to Get Your Token
Steps for enterprise Databricks
  1. Open your Databricks workspace in the browser
  2. Click your user icon (top-right) → Settings
  3. Go to Developer → Access Tokens
  4. Click "Generate New Token"
  5. Give it a name (e.g. Bricksfactory), set a lifetime, and click Generate
  6. Copy the token (starts with dapi...) and paste it above

Security: Token is only stored in-memory for this session. Never saved to disk.
