⚡ Simplest Access — One Role That Covers Everything

If you want to avoid configuring multiple granular roles, a single Contributor role on the Resource Group covers all deployment actions:

Contributor
Scope: Resource Group rg-westus3-t1-services-sandbox-Rakesh-001
✅ Creates ACR   ✅ Pushes Images   ✅ Creates App Plan   ✅ Creates Web App   ✅ Configures Container

Still required separately: Subscription Owner must register the 2 resource providers (one-time action).

Commands for Subscription Owner (one-time setup)
# Step 1: Set the target subscription
az account set --subscription "15ea86a2-d638-44be-a600-6dc6321ccd08"

# Step 2: Register resource providers
az provider register --namespace Microsoft.Web
az provider register --namespace Microsoft.ContainerRegistry

# Step 3: Grant Contributor to deployer
az role assignment create \
  --assignee "Sunil.Kumar@insight.com" \
  --role "Contributor" \
  --scope "/subscriptions/15ea86a2-d638-44be-a600-6dc6321ccd08/resourceGroups/rg-westus3-t1-services-sandbox-Rakesh-001"
Verify Provider Registration
az provider show --namespace Microsoft.Web --query "registrationState" -o tsv
az provider show --namespace Microsoft.ContainerRegistry --query "registrationState" -o tsv
# Both should return: Registered
